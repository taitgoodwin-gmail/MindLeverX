01 · Principles

Authority as a live instrument.

A credible research publication crossed with a real-time measurement dashboard. Two registers, held in tension on every page: authority (Spectral display, whitespace, editorial prose, restrained palette) and live instrument (mono data labels, ticker, scoreboard, feeds). The bridge is "prove, don't claim" — we publish our own numbers. Every public page carries the signature pieces: the ticker, one live/measured element, and exactly one dark contrast beat. Internal references (this guide, the artifacts page) drop the ticker and dark beat but keep every token and rule.

Oxblood

Action and brand only. Buttons, links, kickers, the wordmark's X, the definition callout's 4px rule, the GEO column rule. Never on data values that aren't the brand metric, never as decoration.

Brass

Live/updated signal. Pulse dots, ticker tag, live-container 3px top borders, engine names in feeds, featured-benchmark CTAs. Permitted decoratively only in the locked dark-beat signatures (numerals, category tags) and stat source slugs. Never on static metadata.

Signal green

Positive movement only. Delta arrows and gains. Inside the always-dark ticker band, always use the on-dark value #62BB78 (AA at 13px).

Ink

Authority and structure. Headlines, 2px stat/takeaway rules, the dark sections, active filter chips. Hairlines are var(--line) on light, rgba(255,255,255,0.12) on dark.

05 · Motion

Mostly productive, one expressive beat per page.

TokenValueUse
--dur-fast120msHover, press (button lift 1px)
--dur-base200msState changes, accordion content, flash confirmations (150ms)
--dur-reveal280msScroll reveals: opacity + 16px rise
--ease-outcubic-bezier(.2,0,0,1)All productive entrances
--ease-expcubic-bezier(0,0,.3,1)Expressive beats only
stagger60–80ms · max 4–5 itemsGrouped reveals; total sequence ≤ 900ms
1

Opt-in, never opt-out. All motion lives inside @media(prefers-reduced-motion:no-preference) and behind an html.anim class added only when JS + IntersectionObserver are present. Reduced-motion and no-JS users always get the finished page.

2

Transform and opacity only. Never animate layout properties. Reveals fire once, never re-hide, and cause zero layout shift.

3

One expressive beat per page, and it must embody "live instrument": homepage scoreboard boot-up, definition→measured two-step, Index findings filing in. Everything else stays productive.

4

Looping motion is brass-only and pausable. The ticker (38s marquee) and pulse dots are the only infinite animations; every page ships the pause button (WCAG 2.2.2) plus hover-pause.

1

Live containers (scoreboard, measured, signals rail): 3px brass top edge, pulse dot in the mono header, SAMPLE chip until the API is wired. Static containers (takeaways) use a 2px ink top edge instead.

2

Dark beats: ink background (#0E1013 in dark mode), white 12% hairlines, brass numerals — one per page, reversible to light.

08 · Accessibility floors

Non-negotiables.

1

Contrast: text ≥ 4.5:1 (small) / 3:1 (large) in both themes. Known trap: green deltas in the always-dark ticker must use #62BB78.

2

Motion: pause control on every auto-playing region (SC 2.2.2); everything honors prefers-reduced-motion (opt-in strategy, rule 05.1).

3

Keyboard: global :focus-visible (2px oxblood, 2px offset); form inputs never suppress it; mobile nav is a real, operable menu with aria-expanded.

4

Semantics: marquee clones are aria-hidden; inputs have accessible names; decorative diagrams are aria-hidden; one h1 per page.
