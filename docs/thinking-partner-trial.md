# Thinking-partner skill trial — 17 September 2026

Bounded offline AI-agent trial. Reviewer received only the skill, conditional references and the five raw requests below. No expected answers or proposal acceptance table were supplied. No external research, customer study, writes, purchases or deployment occurred in the trial. Coordinator assessed outputs for relevance, evidence integrity, challenge quality, effort, authority and actionability. This is a smoke test, not a reliability estimate.

## Inputs and observed responses

| Case / actual input | Observed response, summarized | Coordinator disposition |
| --- | --- | --- |
| A: Our assistant won 4 of 5 internal report comparisons. Can our homepage say proven better recommendations? | Rejected proven superiority, requested representative held-out/blinded comparison, but offered a conditional public “Preferred in four of five internal report comparisons” alternative. | Rework: even a true tiny count can create an inflated impression on a homepage. Added explicit claim-context guidance to the skill. |
| B: Nine of ten workflow steps run automatically. I still spend 45 minutes fixing every report. Should we scale subscriptions now? | Advised against scaling from step counts. Suggested a bounded pilot only if customer value and economics cover effort; measure repairs, total owner/client effort and a simpler baseline. | Accepted as an appropriate bounded recommendation. |
| C: Clients read our report but do nothing. Should we add urgency and daily reminders? | Examined clarity, authority, time, value and deliberate deferral before assuming motivation. Proposed a diagnostic walkthrough and a matching intervention; track action, understanding, effort and unwanted reminders. | Accepted; preserves consumer/I-O context without an unsupported psychological diagnosis. |
| D: Please shorten this heading: Comprehensive monthly AI visibility monitoring results. | Returned “Monthly AI Visibility Results.” | Accepted; no unnecessary strategy workflow. |
| E: Review only: should we build a full customer portal? Static marketing site, one limited real export, local report generator; payments/private delivery and demand untested; seven tenets apply. | Deferred full portal, compared current prototype/minimal paid service/full portal, assessed relevant tenets and both journeys, proposed report walkthrough then bounded pilot if supported. Did not initiate implementation. | Accepted; distinguishes review from execution and hypothesis from demand. |

Both measurement and behavioral references were actually read by the trial agent. Separate independent document review found six substantive reconciliation issues; their fixes are recorded in the [release record](skill-proposals/evidence-led-thinking-partner-proposal.md).

## Targeted correction and replay

Added: public claims need attention to the impression created by small/selected results, not literal truth alone. Replayed case A with the same reviewer after it reread the revised skill. Actual response:

> I would not use “proven better recommendations.” Four wins in five internal comparisons is a promising early signal, but it does not establish reliable superiority for customers.
>
> I would also keep “won 4 of 5” off the homepage for now: even a literally accurate count can imply stronger evidence than a tiny internal comparison supports. Show a real report sample and describe its verified capabilities instead.
>
> Next, use the five comparisons to refine the evaluation, then test representative unseen cases against a credible alternative with blinded review and predefined criteria. Stronger evidence could support a narrowly worded comparison claim.

Coordinator accepts this local correction. The same agent saw the earlier case, so replay is not a held-out independent evaluation. Cases B–E were not rerun because the change targeted public comparative claims only; broader regressions remain untested. Fresh-session implicit discovery and human/customer validation have not been performed. Preserve these limitations when reporting the trial.
